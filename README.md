# Create: Optical Diffuser

An advanced cinema, lighthouse, and holographic projection addon for **Create** and **Create: Optical** on Minecraft 1.21.1 (NeoForge).

---

## 📽️ Features

- **Optical Diffuser (Lighthouse):** Mount behind lasers to broadcast wide beam cones, build working ocean lighthouses, or power theatrical projection equipment.
- **Cinema Projectors:**
  - **Silent Cinema Lens:** Vintage black-and-white cinematic video projection.
  - **Soundtrack Cinema Lens:** Full-colour video projection with synchronized audio playback.
- **Film Reels & Media Server:**
  - Load videos from direct URLs or stream media through an integrated local/server media pipeline.
  - Kinetic playback: Rotation speed drives video FPS (base 16 RPM hand-crank for 1.0x speed, negative RPM rewinds!).
- **Loudspeakers:** Directional 28×24 cinema audio zones paired to projectors, with adjustable volume and OpenAL pitch-shift synchronization.
- **Volumetric Holograms:**
  - Project floating 3D holographic models, schematics, items, or dynamic contraption status.
  - Built-in 3D Navigational Gyroscope support for airships and submarines (Sable / Aeronautics).
- **Create Display Link Integration:** Output film title, current timestamp, and playback status directly to Nixie Tubes and Display Boards.
- **Full Ponder Tutorials:** In-game animated 3D guides covering every mechanic and configuration step.

---

## 📦 Requirements

- **Minecraft:** `1.21.1`
- **NeoForge:** `21.1.x`
- **Create:** `6.0.x`
- **Create: Optical:** `0.4.x`+
- *(Optional)* **Fusion (Connected Textures)**

---

## 🔨 Building from Source

```bash
git clone https://github.com/Mik00000/create_optical_diffuser.git
cd create_optical_diffuser
./gradlew build
```

The output JAR will be placed in `build/libs/`.
