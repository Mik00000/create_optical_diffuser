# Context: Create Optical Diffuser

Повна документація архітектури, принципів роботи та історії помилок: [DEVELOPER_GUIDE.md](file:///home/mik/.local/share/atlauncher/instances/AllofAeronauticsNEW/create_optical_diffuser/DEVELOPER_GUIDE.md).

## 1. Quick Summary (Швидкий огляд)
- **Mod**: Create: Optical Diffuser (NeoForge 1.21.1)
- **Платформа**: Minecraft 1.21.1, NeoForge 21.1.x, Create 6.0.10, Create Optical 0.4.2
- **Основні блоки**:
  1. `OpticalDiffuserBlock` (`create_optical_diffuser:optical_diffuser`) — прожектор/маяк, що розгортає тонкий лазер у волюметричний конус світла.
  2. `LeadGlassBlock` (`create_optical_diffuser:lead_glass`) — свинцеве скло (пропускає видиме світло, але на 100% захищає від гамма-радіації; підтримує CTM/Fusion з'єднання).
- **Збірка мода**:
  ```bash
  cd create_optical_diffuser
  ./gradlew build -x test
  cp build/libs/create_optical_diffuser-1.0.0.jar ../mods/
  ```

## 2. Поточний стан механік (Актуальна версія)
1. **Повна відсутність GUI (In-World взаємодія):**
   - Усі налаштування відбуваються в світі без меню.
   - Гайковий ключ Create (**Wrench**): звичайний клік повертає дифузор, **Shift + ПКМ** миттєво демонтує його в інвентар гравця.
2. **Модулі лінз, револьверна карусель та кінопроектор:**
   - **Револьверна карусель (4 слоти на лівій грані):**
     - На лівій грані дифузора розміщено обертовий диск каруселі з валом у центрі.
     - Обертання підключеного вала Create фізично обертає диск та всі 4 вставлені лінзи навколо осі!
     - **Активна лінза:** та, яка в результаті обертання підійшла найближче до передньої/лицьової грані. Вона візуально виділена золотистою світною рамочкою на каруселі.
     - **Вставка/зняття:** Клік ПКМ лінзою по лівій грані вставляє її у вільний слот каруселі. Клік порожньою рукою по лівій грані виймає активну лінзу.
   - **Нові предмети лінз:**
     - `create_optical_diffuser:focusing_lens`: фокусує промінь (Spotlight).
     - `create_optical_diffuser:dispersing_lens`: розсіює промінь (Floodlight).
     - `create_optical_diffuser:silent_projector_lens`: чорно-біле німе кіно, ретро-фільтр зернистості та мерехтіння.
     - `create_optical_diffuser:sound_projector_lens`: кольорове відео, вінтажний фільтр, просторовий 3D-звук OpenAL від позиції блоку.
   - **Кінострічка (Film Reel):**
     - Предмет `create_optical_diffuser:film_reel` із вбудованим валом (shaft).
     - ПКМ у повітрі відкриває GUI для введення URL або кнопку `Browse...` для вибору локального файлу (`mp4`, `mkv`, `webm` тощо через `TinyFileDialogs`).
     - Керування швидкістю відео: кінетичне обертання Create. Базова швидкість 1.0x = 16 RPM (швидкість Create Hand Crank). При 0 RPM — пауза, при негативному RPM — перемотування назад.
   - **Вибір та рендеринг екрану:**
     - Проекторною лінзою: **ПКМ** по блоку вибирає Corner 1, **Shift + ПКМ** вибирає Corner 2.
     - При виборі обох кутів лінза отримує ефект зачарування (glint) і координати в tooltip.
     - Відео транслюється на площину екрану через `DynamicMediaTexture` та `RenderType.entityTranslucentCull`, сумісно з шейдерами Iris і рухомими кораблями Sable. Охоплення `getRenderBoundingBox` гарантує відсутність culling-зникнення.
   - **Мова:** Усі надписи, назви, GUI, чат та тултіпи виконані суто англійською мовою.
3. **Логіка редстоуну та форми променя:**
   - **Рівень 15:** повне вимкнення променя та освітлення (для всіх режимів).
   - **Без модуля (дефолт):** сигнал 0..14 тримає базовий кут $35^\circ$ (вимикається тільки на 15).
   - **З `BEAM_FOCUSER`:** сигнал 0..14 **фокусує** промінь від $45^\circ$ (при 0) до тонких $8^\circ$ (при 14), дальність зростає до 96 блоків.
   - **З `BEAM_CONDENSER`:** сигнал 0..14 **розсіює** промінь від $20^\circ$ (при 0) до широких $70^\circ$ (при 14).
4. **Суворий задній порт лазера:**
   - `canReceive(...)` приймає лазер тільки з протилежного боку від лінзи (`properties.direction() == state.getValue(FACING)`). Лазери з боків чи в переднє скло блокуються.
5. **Кінетичне обертання:**
   - Підключення вала Create знизу обертає корпус і конус світла на 360° зі швидкістю вала (RPM).
6. **Окуляри інженера (Engineer's Goggles):**
   - Показують статус, тип променя, дальність, кут, встановлений модуль лінзи та рівень редстоуну ($X/15$).
7. **Безшовне з'єднання (CTM) для Lead Glass:**
   - Реалізовано через мод **Fusion** (розкладка `pieced`, 80×16 текстура на 5 тайлів у `fusion-overrides/`).
   - У `neoforge.mods.toml` прописано `fusion` як optional client dependency.
8. **Лут і видобуток:**
   - Обидва блоки зареєстровані в `#minecraft:mineable/pickaxe` та мають повноцінні `loot_table`. Швидко добуваються кайлом і гарантовано випадають.
9. **Волюметричний рендеринг:**
   - 12 концентричних оболонок (`SHELL_RADII` від 0.04 до 1.00) з адитивним блендингом `(SRC_ALPHA, ONE)`.
   - Плавний атмосферний спад, пом'якшення силуетних країв, розсіювання Мі при погляді на маяк та Гаусове розжарене ядро.
   - Динамічні тіні (raycast occlusion) видалені, щоб запобігти геометричним спотворенням.
10. **Бойові та термічні лінзи (Collimator & Archimedes):**
   - **Collimator (голчастий лазер):** точковий бронебійний лазер для мобів. 5 ударів/сек, нульове відкидування, знятий кулдаун невразливості.
   - **Лінза Архімеда (Thermal Igniter):** конусний термічний промінь.
     - Смажить сиру їжу як у вигляді викинутих предметів, так і на Create **Depot** та конвеєрах.
     - Кущі, трава, квіти тихо зникають (випаровуються) без спалахів вогню на землі.
     - Вогонь з'являється виключно на пальних блоках (колоди, дошки, шерсть тощо) і ніколи не ставиться у воду або біля води.
     - При швидкості $\ge 200$ RPM плавить кругляк/камінь у магму.
     - **Напівсекретний режим Апокаліпсису:** опція `archimedesOverchargedApocalypseMode` в `create_optical_diffuser-server.toml` (випаровує водойми, агресивний спам вогню скрізь).
